    PETUNJUK DITEMUKAN
    Ingat: huruf A=1 … Z=26, hasil dikembalikan ke 1–26.
    Invers f(x) = ax + b adalah f⁻¹(y) = a⁻¹(y − b) mod 26, dengan a⁻¹ kebalikan a modulo 26 (contoh: 3 × 9 = 27 ≡ 1).
    RUANG INTEROGASI Sorot tersangka dengan lampu, klik untuk membaca berkasnya. Hanya satu tuduhan.

    Alur

    Matematikanya

    Pesan dikunci berlapis: c = f(g(x)). Huruf A=1 … Z=26, hasil selalu mod 26.

    Untuk membuka, balik urutannya: lapis terluar dulu.
    x = g⁻¹(f⁻¹(c))

    Contoh f(x) = 3x + 7, g(x) = x + 5, sandi C = 3:
    f⁻¹(3) = 9(3 − 7) = −36 ≡ 16
    g⁻¹(16) = 16 − 5 = 11 → K

    Urutan salah ⇒ hasilnya bukan kalimat. Karena f(g(x)) ≠ g(f(x)).
